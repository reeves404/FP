My project will analyze paired-end 16S rRNA  sequencing data from hydroponic water-source samples. The goal is to characterize bacterial communities within these sources and compare composition among sources. The dataset I was provided has is 2.8 gb, 236 fastq files being 118 paired IDs. Each sample has a r1 and r2 and the data is already stored at OSC. I was provided access to the directory and have confirmed accessibility. This data comes from unanalyzed data from a previous masters students of Dr. Benitez Ponce. 
I will run nf-core/ampliseq which will include the following steps. 1) Read quality control with FASTQC. 2) Primer removal with Cutadapt. 3) Sequence processing with DADA2. 4) Taxonomic classification with DADA2 and SILVA. 5) Quality reporting with MultiQC. 6) Analysis in R/Quarto. Steps 1-5 will be in part of nf-core/ampliseq while for 6 i will write my own code in R and Quarto. I will store scripts in scripts/, sample information in metadata/, outputs in results/ and the proposal and report in doc/.
